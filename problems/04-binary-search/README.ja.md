### 4. Binary Search

> *ソート済み配列で、每步搜索空間を半分にして目標を見つける。*

**🧩 アルゴリズム**
中央の要素と目標を比較する。答えを含めない半分を捨てる。繰り返す。$O(n)$ ではなく $O(\log n)$。

**🏢 職場**
毎回ゼロから再調査するな。自問する：*「今どちら半分を排除できるか？」* インシデントを二分する。バグを二分する。組織図を二分して、実際に決定権を持つ人を見つける。

**🌍 人生**
壊れた時——人間関係、習慣、プロジェクト——最初から始めるな。*「問題は前半か後半か？」* と聞いてからズームインする。デバッグの大部分は人のデバッグで、人のデバッグも二分法の恩恵を受ける。

**⚠️ アンチパターン**
*"最初から全部読み直そう。"*
それは線形探索だ。$O(\log n)$ ですむことを $O(n)$ で払っている。全てを読む前に、どちら半分を安全に無視できるかを聞け。
