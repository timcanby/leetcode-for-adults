### 7. LRU Cache

> *固定サイズのキャッシュ。一杯になったら最も長く使われていない項目を追い出す。*

**🧩 アルゴリズム**
有界なストアを維持する。アクセス時に最近使用とマークする。ストアが一杯になり新しい項目が来たら、最も長く使われていないものを追い出す。容量は固定、方針は鮮度（最近使用）。

**🏢 職場**
コンテキストのためのワーキングメモリは有限だ。全プロジェクト、全同僚の嗜好、全 API の癖を同時に保持することはできない。健全なやり方：古いものは自然に薄れさせ、**必要な時に素早くリロードできるシステムを構築する**。ドキュメント、Wiki、ブックマークがあなたの追い出し対応型リロード機構だ。

**🌍 人生**
忘れることは失敗ではない——ガベージコレクションだ。スキルは「決して忘れない」ことではなく、「どこで調べるか知っている」ことだ。整理されたノートシステムがあれば、「忘れた」の修正コストは $O(1)$ で済み、$O(\text{気まずさ})$ にはならない。

**⚠️ アンチパターン**
*"全てを覚えておくべきだ。"*
違う。覚えておくべきは*索引*で、*中身*はリロードする。全てを頭に詰め込もうとする人は、キャッシュが溢れた時にバーンアウトするかフリーズする。
