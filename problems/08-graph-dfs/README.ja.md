### 8. Graph / DFS

> *起点から深さ優先探索ですべての到達可能なノードを traverse する。*

**🧩 アルゴリズム**
開始ノードから、各ブランチを可能な限り深く進んでから戻る。辺で到達可能な全ノードを訪問する——あなたの直近のツリーにあるものだけでなく。

**🏢 職場**
組織図はツリーだ；実際の人間関係はグラフだ。A は B に報告していると思うが、A は C とランチも食べ、D と同校で、E に恩がある。情報と意思決定が実際にどう流れるかを理解するには、グラフを traverse する——隠れた辺に本当の影響力がある。

**🌍 人生**
あなたの社交世界はツリーではない。友人の友人の同僚は二ホップ先にいて、まさにあなたが必要な繋がりかもしれない。ネットワークを深さ優先で探索する——一つの糸を最後まで辿ってから戻る——ことは、幅優先でスクロールしても決して出てこない機会を浮かび上がらせる。

**⚠️ アンチパターン**
*"組織図が誰と誰が話しているかを教えてくれる。"*
教えてくれるのは誰が*誰に報告している*かだ。誰が*誰を信頼している*かは教えてくれない。信頼の辺は図には見えないが、現実では決定的だ。木ではなくグラフを描こう。
