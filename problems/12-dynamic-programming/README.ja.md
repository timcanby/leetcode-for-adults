### 12. Dynamic Programming

> *問題を重なり合う部分問題に分割；結果を保存して再計算を回避。*

**🧩 アルゴリズム**
核心の洞察：多くの問題は「今何を選ぶか？」ではなく「この状態にいるとして、ここから達成できる最良の結果は何か？」というものだ。部分解答のテーブルを埋める；各セルは以前のセルに依存する。最終解答はテーブルの一つのセルだ。

**🏢 職場**
キャリアの意思決定は DP であり貪欲法ではない。「この仕事を受けるべきか？」は間違った問いだ。正しい問いは：*「今いる場所——スキル、人脈、貯蓄、精力——から、この状態から到達可能な最良の結果は何か？」* 現在の状態は過去の全決定をエンコードしている。次の手は単なる遷移関数だ。

**🌍 人生**
多くの人生の問題はステップベースではなく状態ベースだ。*「引っ越すべきか / 転職すべきか / 今始めるべきか」* は、今いる場所に相対的にしか意味をなさない。同じ交差点に立つ二人の人は、*状態*——貯蓄、扶養家族、健康、サポートネットワーク——が異なるため、異なる最適手に直面する。同じステップが異なる状態からは異なる結果につながる。

**⚠️ アンチパターン**
*「一般的に正しい選択は何か？」*
一般的に正しい選択などない。*現在の状態から*正しい選択はある。状態なしで問うのは、テーブルなしで DP を走らせるようなもの——毎回ゼロから再計算し、より悪い答えを得る。
