### 14. Boats to Save People

> *各ボートは最大二人まで、重量制限を超えてはならない。最少ボート数を求める。*

**🧩 アルゴリズム**
まずソートする。左ポインタを最軽の人がいる場所に、右ポインタを最重の人に。各ラウンドで、最重の人は**必ず**ボートに乗る——何があっても一枠を取る。唯一の問い：最軽の人が一緒に乗れるか？

- `最軽 + 最重 ≤ limit` → 二人一緒に乗る。`left += 1, right -= 1, boats += 1`。
- `最軽 + 最重 > limit` → 最重の人は誰ともペアになれない（最軽がベストの相棒だった）。一人で乗る。`right -= 1, boats += 1`。

最重の人は「今すぐ対処しなければならない主役」。最軽の人はただ確認している：*「相乗りできる？」* 各ラウンドで少なくとも一つの端点を淘汰し、指数関数的な決定ツリーを線形に圧縮する。

```python
class Solution:
    def numRescueBoats(self, people: list[int], limit: int) -> int:
        people.sort()

        left, right = 0, len(people) - 1
        boats = 0

        while left <= right:
            if people[left] + people[right] <= limit:
                left += 1
            right -= 1
            boats += 1

        return boats
```

> 時間 $O(n \log n)$（ボトルネックはソート）· 空間 $O(1)$

より深い原理：**最も難しい制約を先に処理する。** 最重の人はボトルネック——最もペアにしにくく、最も一人でボートを占領しがちで、後続の選択肢を最も制限する。先に処理すれば、下流の全てが簡単になる。最軽の人——簡単なケース——は柔軟な充填材になり、容量があればどこにでも収まる。

**🏢 職場**
リソース配分の問題に直面した時——予算、人員、締め切り——本能は簡単なタスクを先に片付けて、勢いをつけ、生産的に感じることかもしれない。**それは違う。**

難しい制約がボートの中の最重の人だ。三つの承認が必要なプロジェクト、最も厳しい締め切りのクライアント、全てをブロックする依存関係。それを先に処理する。それは*必ず*解決される——それが勝手に消えるシナリオは存在しない。唯一の問いは、簡単なものを一緒に乗せられるかどうかだ。

ボトルネックが解決されたら、残りのタスク——軽いもの——ははるかに柔軟になる。残った容量のどこにでも収まる。だが簡単なものを先に使ってしまったら、ボトルネックとペアになれる唯一のリソースを浪費し、難しい問題を孤立させて一人でボートを占領させることになるかもしれない。

**🌍 人生**
**問題に直面した時、先に制約を考えるべきだ。それからボトルネックを先に解決する。その後、簡単なことが柔軟に計画しやすくなる——柔軟性を先に使い果たしてから制約に向き合うのではなく。**

本能はこうだ：簡単なものを先に片付ける。小さなタスクを終わらせ、受信箱をゼロにし、勢いを感じる。責任感があるように感じる。だが違う。

最も難しい問題——最重の人——が実際に必要なボート数を決めるものだ。いくら簡単なタスクを片付けてもそれは変わらない。変わるのは、難しい問題が処理された後、簡単なタスクがまだ柔軟な充填材として使えるかどうかだ。もし最軽の人——予備の体力、空いた午後、善意のバッファ——を簡単な勝利に既に使ってしまったら、重い制約とペアになって一隻のボートを節約できた唯一のリソースを失ったことになる。

成熟したやり方：制約を深刻度順に並べる。最も重いものを先に処理する。それから軽くて柔軟なタスクに残った容量を埋めさせる。これはボートの総数を最小化するだけでなく——簡単な部分が本当に簡単であることを意味する。未解決の難しい問題の影がその上に覆いかぶさっていないから。

**⚠️ アンチパターン**
*"まず簡単なタスクを片付けて勢いをつけよう。"*
それは最軽の二人をペアにすることだ。生産的に感じる——ボートが埋まり、タスクが完了するのが見える。だが最軽の人——最重の人とペアになれる唯一の人物——を、後で処理できたペアに使ってしまった。今、最重の人は一人で、ボートが一隻余分に必要だ。簡単なタスクは問題だったことはない；それは*解決策*だった——難しい問題をより少ないボートで解決可能にする柔軟な充填材。最初ではなく、最後に使え。
