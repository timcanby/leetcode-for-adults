### 15. Move Zeroes

> *全てのゼロを配列の末尾に移動する。in-place で、非ゼロ要素の相対順序を維持する。*

**🧩 アルゴリズム**
最も直感的な考えは「ゼロを後ろに押しやる」だ。それは間違いだ。正しいアプローチ：**各非ゼロ要素を、あるべき場所——先頭、順序通り——に配置する。**

二つのポインタ、同じ方向、異なる役割：
- `read` は左から右へ走査し、非ゼロ値を探す。
- `write` は次の非ゼロ要素をどこに置くかを示す。

`read` が非ゼロを見つけるたび、それを `write` の位置に書き、`write` を進める。ゼロ？ゼロは「移動させる」必要はない——非ゼロが前方に圧縮された後に自然に後ろに残るものだ。最後にゼロで埋める。

ループ不変条件：`nums[0:write]` は常に、これまでに見た全ての非ゼロ要素を元の順序で含む。この不変条件は開始時（空）に成り立ち、各ステップ後に成り立ち、終了時にも成り立つ（完全）。

```python
class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        write = 0

        for read in range(len(nums)):
            if nums[read] != 0:
                nums[write] = nums[read]
                write += 1

        while write < len(nums):
            nums[write] = 0
            write += 1
```

> 時間 $O(n)$ · 空間 $O(1)$

より深い原理：**無くしたいものを動かすな——残したいものを圧縮せよ。** ゼロが問題ではない；非ゼロが解決策だ。本当に重要なコンテンツを正しい位置に置けば、ノイズは自動的に後ろに落ちる。

**🏢 職場**
プロジェクトにノイズがある——非推奨にすべきレガシーコード、キャンセルすべき会議、カットすべきタスク——本能は「ノイズに対処する」ことだ。廃止会議をスケジュールし、削除チケットを提出し、クリーンアップスプリントを計画する。

それはゼロを押しやることだ。疲れ、反復的で、最悪 $O(n^2)$——各クリーンアップタスクがさらに多くのクリーンアップを生む。

より良いやり方：**残したいものに集中する。** 本当の仕事——重要な機能、成果を出す人、機能するプロセス——をまず正しい位置に置く。シグナルが前方に圧縮されると、ノイズは自然に後ろに落ちる。「ゼロ削除委員会」はいらない——「非ゼロ圧縮パス」が一つあればいい。重要なものを特定して保持し、残りはあるがままに沈ませる。

**🌍 人生**
人生にはノイズがある——時間を無駄にする習慣、精力を削ぐ約束、価値のない義務。本能はノイズに立ち向かうことだ：悪い習慣をやめ、削ぐ約束をキャンセル、死んだ重荷を剪定する。

だが核心は：**ゼロを動かす必要はない。非ゼロを圧縮する必要がある。**

重要なもの——核となる人間関係、本当の仕事、真の興味——を人生の前方に、あるべき順序で配置する。最良の時間帯、プライムタイム、最初の注意を与える。それらが正しい位置に圧縮されると、ノイズは「除去」される必要はない——残った空間に自然に収まる。

これがよく生きられた人生のループ不変条件だ：`life[0:write]` は常に最も重要なものを正しい順序で含む。ゼロ——時間を浪費するもの、精力を削ぐ人、低価値の約束——は後ろに落ちる。あなたが英雄的に戦ったからではなく、そもそも前の位置を与えなかったからだ。

**⚠️ アンチパターン**
*"悪い習慣を一つずつ断ち切る必要がある。"*
それはゼロを後ろに押しやること——ノイズ要素を個別に対処することで、$O(n^2)$ の努力で脆い。代わりに、残したいものを人生の前方に圧縮せよ。非ゼロ——本当の優先事項、真の興味、本当の人間関係——が解決策であり、問題ではない。それらを正しい位置に置けば、ノイズは自ずと片付く。部屋を片付けるのは雑物を捨てるからではない；何が場所に値するかを決め、残りを沈ませるからだ。
