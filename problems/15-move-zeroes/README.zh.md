### 15. Move Zeroes

> *把所有零移到数组末尾，原地完成，保持非零元素的相对顺序。*

**🧩 算法**
最直觉的想法是"把零往后搬"。这是错的。正确的思路：**把每个非零元素放到它该在的位置——前面，按顺序。**

两个指针，同向，不同职责：
- `read` 从左到右扫描，找非零值。
- `write` 标记下一个非零元素该放在哪里。

`read` 每找到一个非零，就写到 `write` 的位置，然后 `write` 前进。零呢？它们不需要被"搬走"——它们是非零元素被压实到前面之后，自然留在后面的东西。最后补零即可。

循环不变量：`nums[0:write]` 始终包含到目前为止见过的所有非零元素，且顺序正确。这个不变量在开始时成立（空），每一步后成立，结束时也成立（完整）。

```python
class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        write = 0

        for read in range(len(nums)):
            if nums[read] != 0:
                nums[write] = nums[read]
                write += 1

        while write < len(nums):
            nums[write] = 0
            write += 1
```

> 时间 $O(n)$ · 空间 $O(1)$

更深的原理：**别搬你想去掉的——压实你想保留的。** 零不是问题；非零才是解决方案。把真正重要的内容放到正确的位置，噪声自然落到后面。

**🏢 职场**
项目里有噪声——该废弃的遗留代码、该取消的会议、该砍掉的任务——本能是"处理噪声"。排一个废弃会议、提一个清理工单、规划一个清理冲刺。

那是在搬零。累人、重复、最坏 $O(n^2)$——每个清理任务又制造更多清理。

更好的做法：**专注你想保留的。** 把真正的工作——重要的功能、能交付的人、有效的流程——先放到正确的位置。信号被压实到前面之后，噪声自然落到后面。你不需要一个"零清除委员会"——你需要一次"非零压缩扫描"，识别并保留重要的东西，让剩下的自己沉到该沉的位置。

**🌍 人生**
你的生活有噪声——浪费时间的习惯、消耗精力的承诺、毫无价值的义务。本能是去对付噪声：戒掉坏习惯、取消消耗你的承诺、修剪死重量。

但关键是：**你不需要搬零。你需要压实非零。**

把重要的东西——核心关系、真正的工作、真正的兴趣——放到你生活的前面，按它们应有的顺序排列。给它们最好的时段、黄金时间、第一注意力。一旦它们被压实到正确的位置，噪声不需要被"移除"——它自然占据剩余的空间。

这就是好好生活的循环不变量：`life[0:write]` 始终包含最重要的东西，顺序正确。零——浪费时间的事、消耗精力的人、低价值的承诺——落到后面，不是因为你在英勇地对抗它们，而是因为你从一开始就没给它们前面的位置。

**⚠️ 反模式**
*"我得一个一个地戒掉坏习惯。"* 那是把零往后搬——逐个处理噪声元素，$O(n^2)$ 的精力且脆弱。相反，把你想保留的压实到生活的前面。非零——你真正的优先级、真正的兴趣、真正的关系——才是解决方案，不是问题。把它们放对位置，噪声自己就消停了。你不是通过扔掉杂物来收拾房间的；你是通过决定什么值得占位置，让剩下的自己沉下去。
