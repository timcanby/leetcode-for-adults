### 17. Linked List Cycle

> *連結リストにサイクルがあるかを判定する——全ての訪問ノードを保存せずに。*

**🧩 アルゴリズム**
最も直感的なやり方：訪れた各ノードをハッシュセットに記録する。同じノードが二度現れたらサイクルがある。動く、$O(n)$ 時間——だが $O(n)$ 空間がかかる。全履歴をメモリに保持しているからだ。

Floyd のやり方：二つのポインタをリストに入れる。一方は 1 歩/ラウンド、もう一方は 2 歩。サイクルがなければ、速い方が先にリストから出る。サイクルがあれば——両ポインタがリングに入り——これは有限のトラック上の追及問題になる。速いポインタは毎ラウンド 1 歩ずつ距離を詰める。有限の $m$ 個の位置の上で、毎ラウンド +1 なら、最大 $m$ ラウンドで追いつく。「かもしれない」ではなく——「必ず」だ。

```python
class Solution:
    def hasCycle(self, head) -> bool:
        slow = fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

            if slow is fast:
                return True

        return False
```

> 時間 $O(n)$ · 空間 $O(1)$

核心の洞察：**サイクルを検出するのに過去を覚える必要はない。** 異なる速度で動く二つのものが閉じた軌道上にあれば*必ず*出会う——運が良いからではなく、相対速度が一定で軌道が有限だからだ。「以前ここに来たことがあるか？」という記憶が、「閉じたループの上で二つのものが追いかけば、速い方が追いつく」という物理学に置き換わる。

ハッシュセットのやり方が問うのは：*「記録を残したか？」* Floyd が問うのは：*「力学が衝突を保証するか？」* 一方は記憶を必要とし、もう一方は数学だけを必要とする。

**🏢 職場**
パターンを知っている：毎週月曜に金曜に壊れたものを直している。同じ障害、同じ対立、同じコミュニケーションミス。問題を解決しているのではない——サイクルを歩いている。

最も直感的なやり方：遭遇した全ての問題をログに記録し、新しい問題が来たら履歴と照合する。それはハッシュセット——$O(n)$ の精神空間で、しかも常に維持しなければならない。動くが、疲れる：インシデントの全アーカイブを頭に担いでいるからだ。

Floyd のやり方：**記録するのをやめよう。力学を見よう。** 同じ二つのチームが衝突し続けるなら、同じエスカレーションパスが再発するなら、同じボトルネックが毎スプリント再現するなら——包括的な監査でサイクルだと証明する必要はない。異なる速度で動く二つのものが必要だ：速い方（素早くエスカレートする人）と遅い方（ゆっくり進むプロセス）。それらが同じ点で繰り返し出会うなら、それが証明だ。

サイクルは網羅的な記憶で検出されるのではない。動きの*形*で検出される——進捗のない反復。有限のトラック上の二つの速度が、繰り返し出会う。それがサイクルで、解決策はログをより詳細にすることではない。解決策は**その辺を断つこと**——ループがもはや存在しないように構造を変えることだ。

**🌍 人生**
人生のハッシュセット・アプローチ：全ての衝突を記録し、全ての口論をログし、全ての反復パターンを追跡する。「前に起きたこと」の包括的な記録を築き、再び起きた時に認識できるように。動く。だが代价は、全人間関係の全感情履歴を頭に担ぐことだ——$O(n)$ 空間、永遠に。

Floyd のやり方：**全ての口論を覚えている必要はない。力学を見る必要がある。**

ここでの洞察：**反復は記憶で証明する必要はない——異なる速度が必要だ。** 二つのものを動かす：あなたの反応（速い）と根本のパターン（遅い）。あなたの反応が繰り返しパターンと同じ場所に到達するなら——同じ喧嘩、同じ恨み、同じ撤退——あなたはサイクルの中にいる。歴史をカタログ化したからではなく、力学がそれを不可避にするからだ。

そしてより深い真実：**サイクルの中では、速く動いても意味がない。** 速いポインタは速いからサイクルを抜け出すのではない——遅い方を周回するだけだ。サイクルの中でより速く、より激しく、より強く反応しても——ループは断ち切れない。速いポインタが遅いポインタに出会うのは、*トラックが閉じている*からで、遅いからではない。

唯一の出口は**その辺を断つこと**——ループがもはや存在しないように構造を変えることだ。それは新しい会話、新しい境界、新しいプロセスかもしれないし、トラックから entirely 離れることかもしれない。サイクルの中では、一歩前進することはもう一周することだ。出口はステップではなく——構造的な変更だ。

**⚠️ アンチパターン**
*"次はもっと詳細に記録しよう。"*
それはハッシュセット・アプローチ：$O(n)$ の記憶で暴力リコールによりサイクルを検出する。動くが、永遠に払う税金だ——全ての衝突、全てのパターン、「前に起きたこと」の全ての、成長し続けるアーカイブを維持している。Floyd は告げる：そのアーカイブはいらない。必要なのは力学だ。人生の二つのものが同じ点で繰り返し出会うなら、それ*が*証明だ——ログは不要だ。サイクルを断つ代わりにより良い記録に精力を費やすのは、最も高価な否定の形だ：勤勉に見えるが、実際は閉じたトラックの上で速く歩いているだけだ。
