### 18. 3Sum

> *和がゼロになる全てのユニークな三つ組を見つける。出力に重複なし。*

**🧩 アルゴリズム**
三つの数、一つの制約。最も直感的なやり方は三重ループ——$O(n^3)$、全組み合わせを調べ、重複をセットで排除する。総当たりは構造を使わない、ただ回すだけだ。

重要な一手：**次元を落とす。** 三つの数を一度に考えるな。一つを固定し、残りはソート済み区間での Two Sum——既に双ポインタで $O(n)$ で解けるものだ。

ソートする。`nums[i]` を固定。`left = i+1`、`right = n-1`。今は：*「ソート済み部分配列で二つの数を見つけ、和が `-nums[i]` になるようにする」*。ソートの単調性により `sum < target → left を移動`、`sum > target → right を移動`、各ステップで探索空間の一行全体を排除。$O(n^3)$ が $O(n^2)$ に。

重複はスキップで処理：`nums[i] == nums[i-1]` ならこの `i` は既に固定済み——スキップ。三つ組を見つけた後、繰り返しの `left` と `right` 値もスキップ。

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        ans = []
        n = len(nums)

        for i in range(n - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            if nums[i] > 0:
                break

            left, right = i + 1, n - 1

            while left < right:
                total = nums[i] + nums[left] + nums[right]

                if total < 0:
                    left += 1
                elif total > 0:
                    right -= 1
                else:
                    ans.append([nums[i], nums[left], nums[right]])

                    left += 1
                    right -= 1

                    while left < right and nums[left] == nums[left - 1]:
                        left += 1
                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1

        return ans
```

> 時間 $O(n^2)$ · 空間 $O(1)$（ソートと出力を除く）

より深い原理：**思考がソートされたら、前に進み、後ろを振り返るな。** ソートが方向を与える——一歩前進は一つのコミットメントで、単調性が逆転が不要であることを保証する。`i` を固定し、`left` と `right` を内側にスキャンし、排除済みの組み合わせに再訪しない。ポインタは一方向にしか動かない。バックトラックなし、アンドゥなし、「間違えて選んだらどうしよう？」なし。ソートが経路を線形にし、線形とは前進のみを意味する。

**🏢 職場**
複雑な問題が机上に降ってくる——三つのチーム、三つの制約、三人のステークホルダー、全てが整列しなければならない。本能は三つを同時に、並行でジャグルすることだ。それは $O(n^3)$ のやり方：三人、三つのタイムライン、三つの予算の全組み合わせを相互にチェックする。疲れ、遅く、重複を生む——同じ会話を少し違う人たちと三回繰り返す。

より賢い一手：**次元を落とす。** 一つの変数を固定する——最も制約されたもの、最も動かしにくいもの——すると問題はシンプルになる。三つのチームの整列を管理しているのではない；三番目のチームの制約が*固定されたという前提で*、二つのチームの整列を管理している。制約を「最も rigid」順にソートし、最も rigid なものを固定し、残りは既に解き方を知っている問題になる。

そしてここが規律：**思考をソートし、方向にコミットしたら、前に進む——後ろを見続けない。** アルゴリズムでは、`left` は右にしか動かず、`right` は左にしか動かず、`i` は既に固定した値に再訪しない。各ステップはコミットメントだ。職場ではこれは：方向を決めたら——最初に固定する制約を選び、最初に整列するチームを選んだら——スキャン中に自己疑疑し続けない。ソートが方向が正しいという確証を与えた。現在のレイヤーを完全にスキャンして何も見つからなかった時にのみ見直す——スキャンの途中ではなく、道半ばではなく、不安を感じる毎回ではなく。

**🌍 人生**
人生の最も難しい決断は 3Sum のように感じる：キャリア、人間関係、場所の三つの要素が全て整列しなければならない。または：体力、時間、お金。または：欲しいもの、払えるもの、利用可能なもの。本能は三つ全てを同時に頭に持ち、全組み合わせを総当たりすること——$O(n^3)$ の精神的努力、ほとんど同じ不安な計算の重複を生む。

成熟したアプローチ：**優先順位をまずソートし、最も制約されたものを固定して、残りをよりシンプルな問題に落とす。**

最も rigid な制約は何か？最も変えにくいものは？それを固定する。場所かもしれない——今年は引っ越せない。今や問題は「キャリア + 人間関係 + 場所が全て整列」ではなく——「この場所を*与えられた*として、どのキャリア + 人間関係の組み合わせが機能するか？」になった。それはソート済み区間上の二変数問題で、双ポインタが使える：各残り変数の選択肢をスキャンし、「この固定制約の下で何が利用可能か」の単調性がどちらに動くかを教える。

そしてこれがあなたが追っている感覚：**思考がソートされたら、前に進み、振り返らない。** スキャン中に固定された変数を再訪しない。残り二つをスキャン中に「でも間違った制約を固定したらどうしよう？」と聞き続けない。方向にコミットした——ソートがその確証を与えた——今の仕事は前にスキャンし、不可能を排除し、方向が正しかったと信じることだ。正しくソートし、単調性が成立てば、答えは浮かび上がる。成り立たなければ、スキャンが完了した時に分かる——途中で振り返るのではなく、終点に到達して答えが見つからなかった時に。

これが規律だ：**ソート → コミット → 前にスキャン → レイヤーが完了するまで振り返らない。** 各レイヤーには独自の完全なスキャンがある。スキャン完了後にのみ次の `i`、次の固定変数、次のコミットメントのレイヤーに進む。美しいのはこの構造——ソート、固定、スキャン、逆転なし——が 3Sum、4Sum、そして人生の最も難しい多変数決断にも機能することだ。アルゴリズムは教えている：*全てを一度に持つな。rigid なものを固定し、flexible なものをソートし、一方向に前に歩け。*

**⚠️ アンチパターン**
*"全ての可能な組み合わせを考慮して、最高のものを逃さないようにする必要がある。"*
それは $O(n^3)$ の総当たりのマインドセットだ——そして遅いよりも悪い、*麻痺的*だ。三つの自由変数を同時に頭に持とうとする時、空間を効率的に探索しているのではない——その中で溺れている。各「この組み合わせは？」は単調性を使わず、排除せず、コミットしない一歩だ。ソートはまさにこれをしないために存在する。一つの変数を固定し、残りをソートし、前にスキャンする。方向はソートによって与えられる——それを信じ、前に歩き、レイヤーが完了するまで振り返らない。全てを開いたままにするのは網羅性ではない；勤勉に偽装したコミットメントの拒否だ。
