### 18. 3Sum

> *找出所有和为零的不重复三元组。输出不能有重复。*

**🧩 算法**
三个数，一个约束。最直觉的做法是三层循环——$O(n^3)$，每个组合都查一遍，重复用集合去重。暴力法不利用结构，只是在空转。

关键一步：**降维。** 别一次想三个数。固定一个，剩下的问题就是有序区间上的 Two Sum——你已知怎么用双指针 $O(n)$ 解决的事。

排序。固定 `nums[i]`。设 `left = i+1`，`right = n-1`。现在问题变成：*"在有序子数组中找两个数，使其和为 `-nums[i]`。"* 排序带来的单调性意味着 `sum < target → 左移`，`sum > target → 右移`，每一步排除一整行搜索空间。$O(n^3)$ 压成 $O(n^2)$。

去重靠跳过：如果 `nums[i] == nums[i-1]`，这个 `i` 已经固定过了——跳过。找到三元组后，跳过重复的 `left` 和 `right` 值。

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        ans = []
        n = len(nums)

        for i in range(n - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            if nums[i] > 0:
                break

            left, right = i + 1, n - 1

            while left < right:
                total = nums[i] + nums[left] + nums[right]

                if total < 0:
                    left += 1
                elif total > 0:
                    right -= 1
                else:
                    ans.append([nums[i], nums[left], nums[right]])

                    left += 1
                    right -= 1

                    while left < right and nums[left] == nums[left - 1]:
                        left += 1
                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1

        return ans
```

> 时间 $O(n^2)$ · 空间 $O(1)$（不含排序和输出）

更深的原理：**思绪理清后就往前走，不要回头。** 排序给了你方向——每往前一步是一个承诺，单调性保证你永远不需要反转。你固定 `i`，你扫描 `left` 和 `right` 向内收缩，你从不重访已经排除的组合。指针只朝一个方向走。没有回溯，没有撤销，没有"如果我选错了怎么办？"排序把路径变成了线性，线性意味着只进不退。

**🏢 职场**
一个复杂问题砸到你桌上——三个团队、三个约束、三个利益相关者，全要对齐。本能是同时处理三个，并行地抛接一切。那是 $O(n^3)$ 做法：三个人、三条时间线、三个预算的每个组合互相检查。累人、慢，还产出重复——同样的对话跟稍微不同的人说了三遍。

更聪明的做法：**降维。** 固定一个变量——最受限的那个、最难动的那个——现在问题变简单了。你不是在管理三个团队的对齐，而是在*给定*第三个团队的约束被固定后，管理两个团队的对齐。按"最刚性"排序你的约束，固定最刚性的，剩下的问题你已经知道怎么解。

而这正是纪律：**思绪理清并承诺了一个方向后，就往前走——别一直回头看。** 在算法里，`left` 只右移，`right` 只左移，`i` 从不重访已经固定过的值。每一步是一个承诺。在职场里，这意味着：一旦你决定了方向——选了先固定的约束、选了先对齐的团队——在往前扫描的时候别一直自我怀疑。排序给了你方向正确的信心。只有当你完整扫描完当前层、什么都没找到时才回头——不是扫到一半，不是走了一半，不是每次焦虑的时候。

**🌍 人生**
人生最难的决策感觉像 3Sum：三个因素全要对齐——职业、关系、城市。或者：精力、时间、钱。或者：你想要的、你付得起的、可选的。本能是同时把三个都装在脑子里，暴力每个组合——$O(n^3)$ 脑力，产出的还大多是同一个焦虑计算的重复。

成熟的做法：**先排好你的优先级，然后固定最受约束的那个，把剩下的问题降成更简单的。**

最刚性的约束是什么？最难改变的那个？固定它。也许是你的城市——今年搬不了。现在问题不再是"职业 + 关系 + 城市全要对齐"——而是"给定这个城市，什么职业 + 关系组合可行？"这是一个有序范围上的双变量问题，双指针方法适用：扫描每个剩余变量的选项，"在给定约束下什么可选"的单调性告诉你往哪个方向走。

而这就是你在追的那种感觉：**思绪排好之后，就往前走，不回头。** 你不在扫描的时候重访被固定的变量。你不在扫描剩下两个的时候一直问"但万一我固定错了呢？"你承诺了一个方向——排序给了你那个信心——现在你的工作是往前扫描，排除不可能，相信方向是对的。如果你排对了、单调性成立，答案会浮出来。如果没有，你会在扫描完成时知道——不是扫到一半回头看，而是走到尽头、没找到答案时。

这就是纪律：**排序 → 承诺 → 往前扫 → 这层没扫完不回头。** 每层有自己完整的扫描。只有扫完之后才踏入下一个 `i`、下一个固定变量、下一层承诺。美妙的是这个结构——排序、固定、扫描、不反转——适用于 3Sum、4Sum，也适用于人生最难的多变量决策。算法在告诉你：*别一次性把所有东西都端着。固定刚性的，排好灵活的，朝一个方向往前走。*

**⚠️ 反模式**
*"我得考虑每一个可能的组合，才能确保不漏掉最好的。"* 那是 $O(n^3)$ 暴力思维——而且比慢更糟，它是*瘫痪性的*。当你试图同时在脑子里放三个自由变量，你不是在高效探索空间——你在里面淹水。每个"那这个组合呢？"是一步不利用单调性、不排除、不承诺的脚步。排序存在的意义就是让你不用这么做。固定一个变量，排好剩下的，往前扫。方向是排序给你的——相信它，往前走，这层没扫完别回头。把一切都保持开放不是周密；是拒绝承诺，披着勤奋的外衣。
