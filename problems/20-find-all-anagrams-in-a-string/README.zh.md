### 20. Find All Anagrams in a String

> *在 s 中找出所有 p 的异位词的起始位置。*

**🧩 算法**
异位词意味着：相同字符、相同数量、不同顺序。所以你不需要匹配*内容*——你需要匹配*频次*。窗口不是在扩张或收缩寻找最优；它是**固定大小**的，以恰好 `len(p)` 的宽度沿 `s` 滑动。

每一步：`right` 前进一格，加入一个字符。如果窗口超过 `len(p)`，`left` 前进一格，移出最老的字符。窗口始终恰好 `len(p)` 宽——一个沿字符串滑动的固定框架。

在每个位置，比较窗口的字符频次和 `p` 的频次。如果匹配——相同字符、相同数量——那就是一个异位词。记录起始索引。

```python
from collections import Counter

class Solution:
    def findAnagrams(self, s: str, p: str) -> list[int]:
        need = Counter(p)
        window = Counter()
        ans = []
        left = 0

        for right, ch in enumerate(s):
            window[ch] += 1

            if right - left + 1 > len(p):
                window[s[left]] -= 1
                if window[s[left]] == 0:
                    del window[s[left]]
                left += 1

            if right - left + 1 == len(p) and window == need:
                ans.append(left)

        return ans
```

> 时间 $O(n \cdot k)$，$k$ = 字符集大小 · 空间 $O(k)$

更深的原理：**当框架大小固定时，唯一的问题是此刻框架里面是什么。** 你不是在优化长度——你在每个位置检查身份。窗口不伸缩；它滑动。每到一站，它只问一个问题：*"我现在看着的这些，和我找的一样吗？"* 不是"如果我调整一下能不能匹配？"——就是"匹配吗，是或否？"

**🏢 职场**
有些问题不是关于优化的——它们是关于**在固定位置做模式匹配**。你有一个模板：一个岗位要求、一个项目清单、一个团队配置要求。你有一流候选项——简历、项目、团队配置——流过你面前。你的工作不是找最长或最短的拟合，而是用一个固定大小的框架滑过流，在每个位置问：*"这个匹配要求吗？"*

错误在于试图让框架可伸缩。"嗯，这个候选人满足 5 项要求里的 4 项，也许我应该放宽要求……"——不。要求就是要求。窗口就是 `len(p)` 宽。滑过去，检查，继续走。如果当前位置不匹配，别谈判框架——前进到下一个位置。

异位词的洞察更锐利：**内容匹配 ≠ 顺序匹配。** 对的候选人可能没按"正确顺序"列技能——简历看起来可能和你期望的不一样、项目可能没按你偏好的顺序——但如果*能力集合*匹配，那就是异位词。别因为顺序不同就拒绝一个匹配。频次才重要，排列不重要。

**🌍 人生**
人生大多数滑动窗口是变长的——你伸缩框架找最长或最短。但有些情况给你一个**固定框架**：一份工作恰好要求 3 年经验、一个租约恰好 12 个月、一笔预算恰好 $5,000、一个截止日期恰好 2 周。框架不伸缩。你沿着选项滑过去，在每个位置问：*"此刻这个框架里的东西匹配我的需求吗？"*

这里的洞察是：**别在框架固定的时候试图改框架大小。** 当约束是刚性的——预算 $5,000、时间 2 周、团队 3 人——别浪费精力谈判约束。沿着选项滑过去，每个对照要求检查，收集所有匹配。有些位置会匹配；大多数不会。没关系。目标不是让每个位置都匹配；是**找到每个匹配的位置**。

异位词的智慧是：**对的人生可能看起来不像你想象的那样——但如果组件匹配，就是对的。** 你想象的是：城市工作、市中心公寓、2 个孩子、狗。你找到的是：远程工作、郊区房子、2 个孩子、猫。不同顺序、不同排列——但频次匹配。相同字符、相同数量、不同序列。别因为它不符合你期望的顺序就拒绝它。它是你想要的人生的异位词。

**⚠️ 反模式**
*"让我调整窗口大小看看能不能找到匹配。"* 那是把固定窗口问题当成了变长窗口问题。窗口是 `len(p)`——不伸缩。如果当前位置不匹配，答案不是改框架大小；是往前滑。为了强行匹配而改固定框架，就像为了候选人改写岗位要求：你会找到一个"匹配"，但不是你在找的匹配。要求定义框架。别让数据重新定义要求。滑、检查、记录匹配、继续走——框架保持固定，每个找到的异位词都是真的。
