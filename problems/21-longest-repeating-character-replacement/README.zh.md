### 21. Longest Repeating Character Replacement

> *找最长的子串，使得替换最多 `k` 个字符后全部变成同一字母。*

**🧩 算法**
你不是在找一个*已经*合法的窗口。你在找一个你能*让它*合法的窗口——"合法"的意思是"全一个字母，最多 `k` 次替换"。

核心洞察：窗口 `[left, right]` 能变成全一个字母，当且仅当 `(窗口长度) - (窗口内出现最多的字符的频次) ≤ k`。"浪费"就是所有不是主导字母的字符。如果浪费在你的 `k` 替换预算之内，窗口就可行。

所以：扩张 `right`，加入字符。追踪 `max_freq`——当前窗口里出现最多的字符的计数。当 `(right - left + 1) - max_freq > k` 时，窗口的浪费太多了。收缩 `left` 直到浪费回到 `k` 以内。

```python
from collections import defaultdict

class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        count = defaultdict(int)
        left = 0
        max_freq = 0
        ans = 0

        for right, ch in enumerate(s):
            count[ch] += 1
            max_freq = max(max_freq, count[ch])

            while (right - left + 1) - max_freq > k:
                count[s[left]] -= 1
                left += 1

            ans = max(ans, right - left + 1)

        return ans
```

> 时间 $O(n)$ · 空间 $O(k)$，$k$ = 字符集大小

更深的原理：**你不需要一切都一样——你需要差异在你的预算之内。** 主导字符是你押注的东西。`max_freq` 是你的锚——已经在工作的那个。其他一切都是噪声。问题不是"这个窗口完美吗？"问题是"噪声够小、我能吸收吗？"

而这里微妙的美在于：**`max_freq` 只增不减。** 当 `left` 移动时你不下调它，因为你不需要。更高的 `max_freq` 意味着更严格的约束——但你在找*最长*的窗口，所以更严格的约束只会让你对当前答案*更有信心*，不会更少。窗口永远不需要比你已经找到的更小。`ans` 只增。`max_freq` 只增。算法是单调的——它往前走，从不后退。

**🏢 职场**
你不需要一个完美的团队。你需要一个**噪声在预算之内**的团队。

你的 `max_freq` 是你最强的贡献者——扛核心负载的人、锚定团队的技能、已经有效的流程。其他一切都是方差：需要指导的初级、偶尔出故障的工具、需要额外沟通的利益相关者。

`k` 是你的管理预算：你的辅导能力、技术债务容忍度、对摩擦的耐心。窗口——你团队的有效 scope——在 `(总 scope) - (锚已经处理的) ≤ k` 时合法。当噪声超过预算时，你不解雇锚。你缩小 scope——砍掉副项目、减少会议负担、收窄 sprint——直到方差在你能吸收的范围内。

而单调的洞察是：**你最强贡献者的巅峰表现只会更高。** 事情乱的时候你不下调 `max_freq`。你记住峰值——你最好的人独扛整个 sprint 的那次——用它当锚。更低的锚会让你过早收缩。峰值的记忆让你持续扩张。

**🌍 人生**
你不需要完美的人生。你需要**与你想要的差异在你的容忍度之内**的人生。

你的 `max_freq` 是你的主导线——占据你生活最多空间、已经在工作的那个人、那个习惯、那个价值、那个活动。其他一切都是方差：没锻炼的日子、不健康的饭、没深入的对话。`k` 是你的自我同情预算——你给自己的余量、你容忍的不完美、你接受的"够好了"。

你的人生的窗口在 `(你在做的一切) - (已经对齐的) ≤ k` 时合法。当噪声——不对齐的习惯、精力消耗、不匹配你核心的承诺——超过你的容忍度时，你不放弃你的锚。你缩小窗口：丢掉不对齐的承诺、放手精力消耗、收窄 scope——直到方差在你能吸收的人生之内。

而这里的解放性洞察是：**`max_freq` 只增不减。** 你不会在糟糕的一周里把自己的上限调低。你记住你的峰值——每天晨跑、每晚读书、每个朋友都在场时的那个版本的自己——用它当锚。更低的锚会让你过早缩小窗口。峰值的记忆让你持续扩张、持续伸手、让窗口持续增长。

最长的人生不是零噪声的人生。是噪声在 `k` 以内的人生——你是什么和你要什么之间的差异够小、能被吸收。别要求完美。要求方差在预算之内。然后扩张。

**⚠️ 反模式**
*"我需要先把一切都修好才能扩张。"* 那是把 `k = 0`——对噪声零容忍、对方差零预算。窗口缩成 `max_freq` 本身——只有主导字符，没有别的。没有项目、没有人生、没有团队是单一字母的重复。`k` 的全部意义在于**有些噪声是可以吸收的**——预算是用来花的，不是用来攒的。如果你拒绝在一切对齐之前扩张，你就永远不扩张。最长窗口不是零替换的窗口；是替换刚好够用的窗口。花掉预算。扩张。只在噪声真正溢出时才收缩。
