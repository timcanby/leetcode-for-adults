### 22. Find First and Last Position in Sorted Array

> *在有序数组中找到目标值的起始和结束位置。如果不存在，返回 [-1, -1]。*

**🧩 算法**
你不是在找一个目标——你在找目标范围的**边界**。数组有序，所以 `target` 的所有出现都是连续的。问题不是"target 存在吗？"——是"target 从哪里*开始*，到哪里*结束*？"

两次二分搜索：
- `lower_bound(target)` → 第一个 `nums[mid] >= target` 的索引。这是**左边界**——target 范围开始的地方。
- `lower_bound(target + 1) - 1` → 最后一个 `nums[mid] < target + 1` 的索引。这是**右边界**——target 范围结束的地方。

```python
class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        def lower_bound(x):
            left, right = 0, len(nums)

            while left < right:
                mid = left + (right - left) // 2

                if nums[mid] < x:
                    left = mid + 1
                else:
                    right = mid

            return left

        left_idx = lower_bound(target)

        if left_idx == len(nums) or nums[left_idx] != target:
            return [-1, -1]

        right_idx = lower_bound(target + 1) - 1

        return [left_idx, right_idx]
```

> 时间 $O(\log n)$ · 空间 $O(1)$

更深的原理：**找边界不等于找值。** 你可以搜 `target` 然后在下标 5 找到它——但那不告诉你范围是 `[5, 5]` 还是 `[3, 12]`。找到*一个*出现回答的是"它存在吗？"找到*边界*回答的是"它延伸到多远？"

关键在于 `lower_bound` 找的是一个*阈值*，不是一个*值*。`lower_bound(target)` 不是找"target 在哪"——是找"数组从哪里开始 ≥ target"。那个阈值就是左边界。而 `lower_bound(target + 1)` 找的是"数组从哪里开始 ≥ target+1"——target 范围之后的位置。减一，就是右边界。

你不是在问*"这是 target 吗？"* 你是在问*"这是 target 领地开始和结束的边界吗？"* 领地由阈值定义，不由单个命中定义。

**🏢 职场**
加入一家公司时，你不需要找一个用到你技能的*某个*项目。你需要找到你技能适用的**领地的边界**。

找到一个出现——一个项目、一个团队、一个用到你专长的任务——让人安心但具有误导性。它告诉你"是的，我的技能在这里有用"。它不告诉你那是一次性任务还是三年任期。它不告诉你领地从哪开始、到哪结束。

`lower_bound` 的做法：找*阈值*——你的技能水平开始变得相关的第一个项目。那是你的左边界。然后找你的技能*不再是*决定因素的地方——下一层挑战开始的地方、senior+ 专长接管的地方。那是你的右边界。中间的领地是你的操作范围。

而职场洞察是：**如果左边界和右边界相同——如果 `lower_bound(target) == lower_bound(target + 1)`——target 不在数组里。** 你找到了阈值但没找到领地。公司*理论上需要*你的技能水平，但没有一个角色*在用*它。那是职业的 `[-1, -1]`：技能名义上被要求但范围是空的。知道边界——而不是只找到一个命中——告诉你你是真的被需要还是只是技术上合格。

**🌍 人生**
你不需要找到*一个*快乐的时刻。你需要找到**范围**——让快乐可持续的条件。

找到一个好日子——一次心流、一场真实的对话——是单次命中。它告诉你"快乐是可能的"。它不告诉你那快乐是一次性的还是反复的模式。它不告诉你快乐领地从哪*开始*、到哪*结束*。

`lower_bound` 的人生做法：找*阈值*——快乐开始的第一个条件。也许是："当我睡 7+ 小时并且每周见一个亲密朋友。"那是左边界。然后找它结束的地方——快乐不再稳定的条件、压力下一层开始的地方。也许是："当我每周承担超过 2 个承诺时。"那是右边界。

中间的领地是你的快乐范围。不是追一个峰值，而是一**条带的条件**——快乐可持续的地方。你不是在找一个单次命中——你在找命中*被保证*的范围的边界。

而人生洞察是：**如果左边界和右边界相同——如果快乐的条件窄到范围为空——target 不在数组里。** 你找到了阈值（快乐*可能*）但没有领地（快乐*不可持续*）。那是人生的 `[-1, -1]`：理论上可达但实践上不可及。解法不是更努力地追那个单次命中。解法是**拓宽范围**——降低阈值、放宽条件、扩大快乐生存的领地——让边界之间足够宽，容得下一段人生。

**⚠️ 反模式**
*"我找到了一个实例——证明它在那。"* 在下标 5 找到一个出现告诉你 target *存在*。它不告诉你范围是 `[5, 12]` 还是 `[5, 5]`，也不告诉你 5 是不是巧合。单次命中回答"它存在吗？"——错误的问题。正确的问题是"它从哪*开始*、到哪*结束*？"——边界，不是中间。找边界和找一次命中花同样的 $O(\log n)$——两次二分而不是一次——但它告诉你领地的*形状*，而不只是"它非空"。而知道形状——边界、范围、事情从哪开始到哪结束——才是让你判断这块领地值不值得住的依据。
