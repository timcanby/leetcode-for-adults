### 23. Bubble Sort

> *隣接ペアを繰り返し比較し、順序に入れ替える。各パスで最大の未ソート要素が正しい位置に「バブルアップ」する。*

**🧩 アルゴリズム**
バブルソートは計算機科学で最も軽蔑されるアルゴリズムだ——$O(n^2)$、素朴で、最初に学んでから二度と使わないとすぐ学ぶもの。だがその仕組みにはクイックソートにはない教訓がある。

各パス：左から右へ歩く。隣接ペアを比較。順序が違えば交換。一つの完全なパスの後、最大の要素は「バブルアップ」して末尾に到達——最終位置にある。次のパスは一つ少ない要素を処理する。あるパスで交換が一つも起きなかったら——全てが既に整っているという意味——停止。

```python
def bubble_sort(nums):
    n = len(nums)

    for end in range(n - 1, 0, -1):
        swapped = False

        for i in range(end):
            if nums[i] > nums[i + 1]:
                nums[i], nums[i + 1] = nums[i + 1], nums[i]
                swapped = True

        if not swapped:
            break

    return nums
```

> 時間 $O(n^2)$ 最悪、$O(n)$ 最良（ソート済み）· 空間 $O(1)$

より深い原理：**最大の問題が最初に表面化する。** 各パスは最大の未ソート要素を末尾に押しやる——最も不釣り合いなものが最初に露呈され修正される。問題を狩る必要はない；シーケンスを歩けば、大きなものは隣との衝突で自ら露呈する。

そして `swapped` フラグが秘密の知恵だ：**完全なパスで交換が一つも起きなければ、完了している。** 事前に完了を知る必要はない。パスを作り続けるだけで、摩擦の不在*が*秩序が達成されたというシグナルだ。ソート状態は全要素をチェックするのではなく——摩擦が止んだことを観察することで検出される。

**🏢 職場**
組織の最大の問題が最初に表面化する。大監査で見つける必要はない——チームを歩き、人ごとに隣接する関係を比較する。摩擦がある場所——順序が違うペア、隣より大きい役割——そこに最大の未ソート要素がある。それらを交換する：報告構造を再調整し、責任の境界を明確にし、過負荷の人を動かす。

各パスの後、最大の不一致は最終位置にバブルアップ——安定し、ソートされ、隣との摩擦をもう作らない。それからもう一パス歩き、次に大きい不一致が表面化する。

そして `swapped` フラグがリーダーシップの洞察だ：**組織を一パス歩いてコンフリクトが一つも起きなければ、ソート済みだ。** 全レポート、全メトリクス、全プロセスをチェックする必要はない。完全なウォークスルーで何も異常が見つからなければ——摩擦なし、不一致なし、交換が必要なペアなし——組織は安定している。摩擦の不在*が*証明だ。監査をやめよう。最適化をやめよう。完了だ——次の再編が新しい未ソート要素を導入するまで。

罠はバブルソートが $O(n^2)$ だということ——各パスは高価で、$n$ パス必要かもしれない。組織では、これは「毎週全社を再編しない」という意味だ。だがパス全体をスキップしないことも同様だ。健全なパターン：定期的にチームを歩き、最大のコンフリクトを表面化させ、解決し、摩擦がなくなったら止める。これを行う組織——定期的なパス、小さな交換、早期停止——は、二年に一回の大再編や全くチェックしない組織より健全だ。

**🌍 人生**
人生の最大の問題が最初に表面化する——それらを許せば。狩る必要はない。日ごとに人生を歩き、隣接する瞬間を比較する：昨日 vs 今日、今週 vs 先週、この約束 vs 次。摩擦がある場所——順序の違う人間関係、スロットより大きい習慣、隣を圧迫する約束——そこに最大の未ソート要素がある。

人生のバブルソート・アプローチ：**全てを一度に直そうとするな。最大の摩擦を直し、安定させ、もう一パス。** 各パスは最大の不一致を正しい場所に移す。それから次に大きいものが表面化する。小さな問題を先に解決するのではない——大きなものを先に解決する。大きなものは隣と衝突し、可視的な摩擦を作るからだ。

そして `swapped` フラグが人生の知恵だ：**人生を一パス歩いて摩擦が一つも起きなければ、ソート済みだ。** 全詳細を日記にし、全習慣を監査し、全時間を最適化する必要はない。一週間の完全なウォークスルーで何も異常が見つからなければ——緊張する人間関係なし、溢れる習慣なし、隣を圧迫する約束なし——人生は安定している。摩擦の不在*が*証明だ。最適化をやめよう。存在しない問題についての日記をやめよう。生きよう。

規律は、バブルソートが効率ではなく**正直さ**についてであることを知ることだ。それは見栄張りを拒絶するアルゴリズムだ。実際のシーケンスを歩き、実際の隣を見て、何かが本当に乱れている時にのみ動く。巧妙な分割なし、分割統治なし、先飛ばしなし。ただ：歩く、見る、直す、摩擦が止まったら止める。それは配列をソートする最速の方法ではない。だが人生をソートする最も正直な方法かもしれない。

**⚠️ アンチパターン**
*"まず小さなものを直せば、大きなものは自ずと整う。"* それは挿入ソートであり、バブルソートではない——そして逆だ。小さなものは大きなものを*直さない*；大きなものは隣との衝突と摩擦を作り続け、直接対処するまで止まらない。バブルソートが機能するのは、最大の未ソート要素が*必ず*表面化するからだ——隠せない、周囲の全てより大きく、自分のレベルに到達するまで隣を圧迫し続けるからだ。小さな問題は無期限に隠れる；大きなものは隠れない。最大の摩擦を先に直し、安定させ、繰り返す。小さな問題はプロセスの中で自ずと解決するか、十分に大きくなって摩擦を作る時に表面化する。下から上ではなく——上から下へソートし、小さなものに自分のレベルを見つけさせよう。
