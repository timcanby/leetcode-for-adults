### 24. Selection Sort

> *最小要素を見つけ、位置に配置し、繰り返す。各パスで一つの要素を最終位置に固定する。*

**🧩 アルゴリズム**
選択ソートは**意図的コミットメント**のアルゴリズムだ。未ソート領域全体を走査し、最小の要素一つを見つけ、最前に配置する——取り消し不能、永久に、最終位置に。それから残りで同じことをする。そしてまた。全てが所定の位置に収まるまで。

ためらいなし。「後で調整する」なし。各パスは正確に一つの決定——最小値——を選び、完全にコミットする。位置 `i` に置かれた要素は二度と動かない。完了した。安定した。最終だ。

```python
def selection_sort(nums):
    n = len(nums)

    for i in range(n):
        min_idx = i

        for j in range(i + 1, n):
            if nums[j] < nums[min_idx]:
                min_idx = j

        nums[i], nums[min_idx] = nums[min_idx], nums[i]

    return nums
```

> 時間 $O(n^2)$——常に、ベストケースのショートカットなし · 空間 $O(1)$

より深い原理：**全てを見てからコミットする。** バブルソートが局所的な摩擦に出会ったら行動するのとは異なり——選択ソートは残りの領域全体を*完全に*走査するまで行動を拒否する。最初に見つけた不順のペアを交換しない。待つ。全候補をチェックする。全てを見てから選択する——そしてその選択は最善のものであり、最初のものではない。

トレードオフはコストだ：選択ソートは配列が既にソート済みでも $O(n^2)$ だ。各パスで残りの領域全体を走査するからだ。バブルソートが享受する「無料の」早期退出は永遠にない。意図的さには代償がある：見る完全なコストを常に払う、それが既に知っていたことを確認するだけの時でさえ。

**🏢 職場**
ある決定は選択ソートの扱いに値する：**全てを走査し、最善のオプションにコミットする、取り消し不能に。**

採用は教科書的なケースだ。最初の「まともそうな」候補者を採用しない——それはバブルソートだ、最初の局所的摩擦に行動する。候補者プール全体を走査する。全員を面接する。比較する。全候補者を見てからオファーを出す——そしてオファーは最善の人に行く、最初の「まともな」人ではなく。一度採用すれば、その人は位置にいる。最終だ。「後で並べ直す」ことはしない。

規律は**取り消し不能さ**だ。選択ソートが要素を位置 `i` に置く時、それは完了——二度と再訪されない。定居領域は一度に一要素ずつ成長し、各追加は永続的だ。採用ではこれは：既に決定を下している間に「たぶん」のバックアップ候補者の山を保持しない。まず全フィールドを走査し、最善を選び、コミットし、残りの候補者で次の位置に進む。コミットメントが既定の決定を再訪する認知負荷から解放する——だが実際に再訪を拒否した場合のみ。

そしてコスト：チームが既に良好でも選択ソートは $O(n^2)$ だ。最初の候補者が素晴らしくても、毎回全候補者プールを走査する。それが「直感が最初の候補者を完璧だと言っても完全な面接ラウンドをしなければならない」税だ。無駄に感じる。違う。完全な走査が取り消し不能にコミットする確証を与える。全てを見ていなかったら、ヘッジするだろう——そしてヘッジはコミットメントの反対だ。

**🌍 人生**
人生の最大の決定は選択ソートに値する：**全てを走査し、最善を選び、取り消し不能にコミットし、振り返らない。**

どこに住むか。誰と人生を築くか。どのキャリアにコミットするか。これらはバブルソートの問題ではない——最初の摩擦を直して残りが自然に収まることを期待しない。これらは選択ソートの問題だ：フィールドを走査する——全都市、全真剣な関係オプション、全現実的なキャリアパス——そして*最善の*ものを選ぶ、最初の容認可能なものではなく。

そしてアルゴリズムがエンコードする人生の教訓：**一度置いたら、それが最終だ。** 位置 0 の要素は決して動かない。あなたが下した決定——この都市、この人、このキャリア——は安定した。「もし違う選択をしていたら？」の山を保持しない。コミットした後にフィールドを再走査しない。定居領域は定居している。残りの決定は*次の*位置についてであり、*残りの*オプションを使い、既に配置したものを再訪するのではない。

コスト：これは、*当時*利用可能な全てを走査したことを受け入れることを意味する——そして世界は今、当時利用できなかった新しいオプションを持っているかもしれない。選択ソートはソート済み領域を再走査しない。前にあるもの、残っているものだけを見る。規律は：定居した過去を再走査しない。「もし違う都市/人/キャリアを選んでいたら」を毎年再開しない。当時全フィールドを走査した。最善を選んだ。配置された。残りで前に進む。

そして知恵：**選択ソートに近道はない。** 人生が既に良くソートされていても——正しい都市、正しい人、正しいキャリア——*確認*のコストを払う。気分が正しいからといって完全な走査をスキップできない。完全な走査が取り消し不能なコミットメントの権利を*獲得*するものだ。スキップすれば、コミットではなく推測している。見る完全なコストを払う。それからコミットする。それから振り返らない。

**⚠️ アンチパターン**
*「まず十分に良さそうな最初のオプションを選んで、後で調整しよう。」* それは選択ソートの問題にバブルソートを適用すること——全フィールドを走査して最善にコミットするのではなく、最初の容認可能なオプションに行動すること。小さな決定（何を食べるか、次にどのタスクをするか）ではバブルソートは問題ない：局所的な摩擦に行動し、直し、進む。だが取り消し不能な決定——どこに住むか、誰にコミットするか、何を築くか——では、最初の容認可能なオプションに行動するのは罠だ。「柔軟性を保っている」のではなく、フィールドを走査する作業を拒否している。そしてその拒否のコストは、できたはずのものより悪く選ぶことだ。選択ソートは言う：全てを見よ、最善を選べ、完全にコミットせよ、見るコストが良く選ぶための代償であることを受け入れよ。近道はない。完全な走査があるか、しなかった後悔があるかだけだ。
