### 24. Selection Sort

> *找到最小元素，交换到位，重复。每轮把一个元素锁定到最终位置。*

**🧩 算法**
选择排序是**刻意承诺**的算法。它扫描整个未排序区域，找到最小的那个元素，放到最前面——不可撤回、永久、在它的最终位置。然后对剩下的再来一遍。再来一遍。直到一切就位。

不犹豫。不"我稍后回来调整"。每轮只做一个决定——选最小值——然后完全承诺。放在位置 `i` 的元素永远不会动了。它完成了。安定了。最终。

```python
def selection_sort(nums):
    n = len(nums)

    for i in range(n):
        min_idx = i

        for j in range(i + 1, n):
            if nums[j] < nums[min_idx]:
                min_idx = j

        nums[i], nums[min_idx] = nums[min_idx], nums[i]

    return nums
```

> 时间 $O(n^2)$——永远如此，没有最好情况捷径 · 空间 $O(1)$

更深的原理：**看清一切之后再承诺。** 冒泡排序遇到局部摩擦就行动——选择排序不行动，直到它*完整地*看过剩余区域。它不会换它看到的第一对错位。它等。它检查每个候选。只有看完了所有候选才做选择——而那个选择是最优的，不是第一个。

代价是：选择排序即使数组已经有序也是 $O(n^2)$，因为它每轮仍然要扫描整个剩余区域。它永远享受不到冒泡排序的"免费"提前退出。刻意是有代价的：你总是要付看的全部成本，即使看的结果只是确认了你已经知道的。

**🏢 职场**
有些决定配得上选择排序的待遇：**看完一切，然后承诺最优的，不可撤回。**

招聘是教科书案例。你不招第一个看起来还行的候选人——那是冒泡排序，对第一个局部摩擦就行动。你扫整个候选人池。你面所有人。你比较。只有看完所有候选人才发 offer——而 offer 给最优的人，不是第一个看起来行的。一旦你招了人，他就在位置上了。最终。你不会"回头重新排一遍"。

纪律在于**不可撤回性**。当选择排序把元素放在位置 `i` 时，它完成了——永远不会被重访。已安置区域一次一个元素地增长，每次添加都是永久的。在招聘中这意味着：别在做决定的同时还保留一堆"可能"的备选。先扫完整个场子，选最优，承诺，然后带着剩余候选人进入下一个位置。承诺让你从重访已定决定的认知负担中解放——但前提是你真的拒绝重访。

而代价是：选择排序即使团队已经很好也是 $O(n^2)$。你每次仍然扫整个候选人池，即使第一个就很棒。这就是"即使直觉告诉你第一个就很完美，你仍然要做完整轮面试"的税。感觉浪费。不是。完整的扫描是让你有信心不可撤回地承诺的依据。如果你没看完一切，你就会犹豫——而犹豫是承诺的反面。

**🌍 人生**
人生最大的决定配得上选择排序：**看完一切，选最优，不可撤回地承诺，永不回头。**

住哪个城市。和谁共度一生。承诺什么职业。这些不是冒泡排序问题——你不会修遇到的第一个摩擦然后指望其余自己安定。这些是选择排序问题：你扫完场子——每个城市、每段认真的关系选项、每条现实的职业路径——然后你选*最优的*，不是第一个看起来可接受的。

而算法编码的人生课是：**一旦你放下了，就是最终。** 位置 0 的元素永远不动。你做的决定——这个城市、这个人、这个职业——安定了。你不会留一堆"如果我选了别的会怎样"。你不会在承诺之后重新扫场子。已安置的区域已安置。剩下的决定是关于*下一个*位置，用*剩余的*选项，不是重访你已经放好的。

代价是：这意味着你要接受你*当时*扫完了所有可选的东西——而世界现在可能有了当时不存在的选项。选择排序不重扫已排序区域。它只往前看，看剩下的。纪律是：别重扫已定的过去。别每年重新打开"如果我选了不同城市/人/职业会怎样"的问题。你当时扫了全场。你选了最优。它放好了。带着剩余的往前走。

而智慧是：**选择排序永远没有捷径。** 即使你的人生已经排好了——对的城市、对的人、对的事业——你仍然要付*确认*它的成本。你不能因为感觉对就跳过完整扫描。完整扫描是你*赢得*不可撤回承诺权的依据。跳过它，你不是在承诺——你在猜。付看的全部成本。然后承诺。然后不回头。

**⚠️ 反模式**
*"我先选第一个看起来够好的，以后再调。"* 那是用冒泡排序的方式做选择排序的事——对第一个可接受的选项就行动，而不是扫完全场承诺最优。小事（吃什么、下一个做什么任务）用冒泡排序没问题：遇到局部摩擦就行动、修好、继续。但不可撤回的决定——住哪、和谁、做什么——用冒泡排序是个陷阱。你不是在"保持灵活"；你在拒绝扫场子的功课，而拒绝的代价是选得比你本可以的更差。选择排序说：看完一切，选最优，完全承诺，接受看的成本就是选得好的代价。没有捷径。只有完整扫描或不做扫描的遗憾。
