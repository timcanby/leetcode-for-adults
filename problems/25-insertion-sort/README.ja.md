### 25. Insertion Sort

> *各要素を取り出し、左側のソート済み領域の正しい位置に挿入する。*

**🧩 アルゴリズム**
挿入ソートは走査でも交換でも選択でもソートしない。**挿入**でソートする——各要素を取り出し、ソート済み領域を左にスライドさせて、あるべきレベルを見つけ、本棚に本を正しい場所に差し込むように配置する。

ソート済み領域は左から成長する。各ステップ：次の未ソート要素を掴み、より大きなものを全て左に押し越え、あるべき場所に落とす。上の要素は各々一つ右にシフトする——押しやりであって、交換ではない。要素は「末尾に移動」され（バブル）「全体から選ばれる」（選択）のではない。**あるべき場所に配置される**——既に安定したものに対して。

```python
def insertion_sort(nums):
    for i in range(1, len(nums)):
        cur = nums[i]
        j = i - 1

        while j >= 0 and nums[j] > cur:
            nums[j + 1] = nums[j]
            j -= 1

        nums[j + 1] = cur

    return nums
```

> 時間 $O(n^2)$ 最悪、$O(n)$ 最良（ほぼソート済み）· 空間 $O(1)$

より深い原理：**孤立して選ぶのではない——既に安定したものに対して選ぶ。** 要素は抽象的に「正しい位置」を持たない。その位置は左にある全てに依存する——既に構築されたコンテキスト。異なるソート済み領域に挿入すれば、異なる場所に着地する。同じ要素、異なるコンテキスト、異なる配置。

そして美しさ：**配列がほぼソート済みの時、挿入ソートは $O(n)$ だ。** 配列が真に混沌としていなければ、完全な $O(n^2)$ コストを払わない。ものが*ほぼ*整順している時——ほんの数要素がわずかにずれている——挿入ソートは滑るように進む。各ずれ要素を短い距離だけあるべきレベルまで歩かせて止める。コストは各要素があるべき場所からどれだけ離れているかに比例し、配列の総サイズには比例しない。小さな混乱、小さなコスト。

**🏢 職場**
チームに参加する時、組織図を再構築できない。**挿入される**——既に位置にある人々の中の、既存のソート済み構造に。あなたの配置は既にそこにいる人々に*相対的に*どこに合うかに依存する。同じ人、異なるチームに挿入されれば、異なる役割に着地する。あなたの「正しい位置」は絶対的ではない——コンテキスト依存だ。

挿入ソートの職場の知恵：**全てを再ソートする必要はない。既に安定したものの中で自分のレベルを見つける必要がある。** 既存の階層を左に歩く——あなたの先輩性、専門性、所有権が明らかに超える人々を通り過ぎ——属する場所で止まる。全員を飛び越えようとしない（それは挿入ではなく再ソート）。底に縮まない（それも挿入ではなく自己降格）。左の全てがより大きく右の全てがより小さいレベルを見つける。それがあなたの位置だ。

そして「ほぼソート済み」の洞察：**チームが既にほぼ組織化されている時、新入社員は $O(n^2)$ の混乱を起こさない。** 一人の新人が参加し、上位の数人を通り過ぎ、スロットに収まる。チームは再編しない。定居領域は変わらない。境界が一つだけ移動し、コストはその人がどれだけ歩いたかに比例し、チームサイズには比例しない。うまく機能するチームは新メンバーを優雅に吸収する。混沌としたチーム——各挿入が組織の半分を通り過ぎる——は毎回完全な $O(n^2)$ コストを払う。教訓：**チームをほぼソート済みに保てば、各挿入は安い。混沌に漂わせれば、新人のたびに再ソートが発生する。**

**🌍 人生**
新しい都市、新しいコミュニティ、人生の新しい段階に、白紙で入ることはない。**挿入される**——既存の社会構造に、既に安定した人々の中に、既に構築されたコンテキストに。どこに着地するかは、既にそこにあるものに*相対的に*どこに合うかに依存する。

同じあなた——同じスキル、性格、価値観——異なる都市に挿入されれば、異なる社会的位置に着地する。ある都市では、確立した友人グループより少し遅れた新人。別の都市では、地元の人より上位の専門家。あなたの「正しい位置」はあなたの属性ではない——*このコンテキストにおけるあなた*の属性だ。要素は自分の位置を選ばない。周囲のソート済み領域がどこに合うかを決定する。

そして人生の「ほぼソート済み」の知恵：**人生が既にほぼ整順している時、各新しい段階——新しい仕事、新しい人間関係、新しい都市——は $O(n)$ の挿入であり、$O(n^2)$ の再ソートではない。** 新しいコンテキストに歩き込み、あなたより上位のいくつかを通り過ぎ、レベルに収まり、人生の残りはほとんど動かない。コストは小さい、ソート済み領域が既に安定していたから。全てを再編する必要はなかった——新しいピースが安定したピースの中のどこに合うかを見つけるだけでよかった。

だが人生が混沌としている時——各新しい段階が全てを再ソートする時——各移行は $O(n^2)$ だ。新しい仕事のたびに全ルーティンを再考する。新しい人間関係のたびに全既存の約束を再交渉する。教訓：**人生をほぼソート済みに保て。** 既に機能している習慣、人間関係、ルーチン——その安定領域を維持する。そうすれば各挿入は必要なコストだけを払う：あなたがいる場所から合う場所までの距離であり、ゼロから再構築する完全なコストではない。

そして最も優しい洞察：**挿入ソートは新しい要素に左の全てより良くなることを求めない。自分のレベルを見つけることを求める。** 全員に勝つ必要はない。最良である必要はない。明らかにあなたより大きいものを通り過ぎ、属する場所で止まり、ソート済み領域に吸収してもらえばいい。目標は最前列にいることではない。目標は*整順*していること——つまり、あるべき場所にぴったりいること、高すぎず低すぎず。

**⚠️ アンチパターン**
*「新しいコンテキストに参加する時、全てをゼロから再構築する必要がある。」* それは挿入ではない——配列全体の再ソートだ。挿入ソートの全前提は、ソート済み領域が*既に安定しており*、新しい要素がその中で自分の場所を見つけるということだ。各移行を完全な再ソートとして扱えば——ルーティンを再構築し、全人間関係を再交渉し、全役割を再定義すれば——$O(n)$ であるべきものに $O(n^2)$ を払っている。ソート済み領域には理由がある：それは以前の挿入が蓄積した秩序だ。それを尊重する。そこに歩き入れる。自分のレベルを見つける。必要なものだけをシフトする——必要なものだけを——残りは安定したままにしておく。ほぼソート済みの人生に挿入するコストは小さい。混沌とした人生を再ソートするコストは全てだ。
