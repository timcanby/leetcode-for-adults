### 25. Insertion Sort

> *拿起每个元素，插入到左侧已排序区域的正确位置。*

**🧩 算法**
插入排序不靠扫描、交换或选择来排序。它靠**插入**——拿起每个元素，在已排序区域里轻轻向左滑动，直到找到它的层级，就像一本书被插到书架上正确的位置。

已排序区域从左边生长。每一步：抓起下一个未排序元素，向左走过所有比它大的，落到它该在的地方。上面的元素各右移一格——一个推移，不是交换。元素不是被"移到末尾"（冒泡）或从全场中"选出"（选择）。它是**被放到适合的位置**——相对于已经安定的东西。

```python
def insertion_sort(nums):
    for i in range(1, len(nums)):
        cur = nums[i]
        j = i - 1

        while j >= 0 and nums[j] > cur:
            nums[j + 1] = nums[j]
            j -= 1

        nums[j + 1] = cur

    return nums
```

> 时间 $O(n^2)$ 最坏，$O(n)$ 最好（近乎有序）· 空间 $O(1)$

更深的原理：**你不在真空中做选择——你在已安定的背景下做选择。** 元素在抽象中没有"正确位置"。它的位置取决于左边的一切——已经建好的上下文。把它插进不同的已排序区域，它落在不同的地方。同样的元素，不同的上下文，不同的位置。

而美妙之处在于：**当数组近乎有序时，插入排序是 $O(n)$。** 除非数组真的混乱，否则它不付全部 $O(n^2)$ 成本。当东西*几乎*有序——只有几个元素略微错位——插入排序滑过去。它把每个错位元素走一小段距离到它的层级，然后停下。成本正比于每个元素离它该在的位置有多远，不是数组的总大小。小偏差，小成本。

**🏢 职场**
加入一个团队时，你不能重建组织架构图。你被**插入**——进入一个已排序的结构，在已经在位的人中间。你的位置取决于你相对于已在那里的人*适合在哪*。同样的人，插进不同的团队，落到不同的角色。你的"正确位置"不是绝对的——是相对于上下文的。

插入排序的职场智慧：**你不需要重排一切。你需要在已安定的东西中间找到你的层级。** 向左走过现有的层级——走过那些资历、专长、或归属权明显超过你的人——在属于你的地方停下。别试图跳过所有人（那不是插入，那是重排）。别缩到底部（那也不是插入，那是自我降级）。走到左边的一切都比你大、右边的一切都比你小的那个层级。那就是你的位置。

而"近乎有序"的洞察是：**当团队已经大致组织良好时，一个新员工不会造成 $O(n^2)$ 的干扰。** 一个新人加入，走过他资历更高的几个人，嵌入。团队不重组。已安定区域不变。只有边界移动——一格——成本正比于这个人走了多远，不是团队规模。一个运作良好的团队优雅地吸收新成员。一个混乱的团队——每次插入都要走过半个组织——每次都付全部 $O(n^2)$ 成本。教训：**保持你的团队近乎有序，每次插入就便宜。让它漂向混乱，每个新员工都触发重排。**

**🌍 人生**
你不会带着空白页进入一个新城市、新社区、或人生的新阶段。你被**插入**——进入一个已有的社会结构，在已经安定的人中间，进入一个已经建好的上下文。你落在哪取决于你相对于*已经在那的东西*适合在哪。

同样的你——同样的技能、性格、价值观——插进不同的城市，落在不同的社交位置。在一个城市你是稍微落后于既定朋友圈的新人。在另一个你是资历超过本地人的专家。你的"正确位置"不是你的属性——是*你在这个上下文中*的属性。元素不选自己的位置。它周围的已排序区域决定它适合在哪。

而人生的"近乎有序"智慧：**当你的生活已经大致有序时，每个新阶段——新工作、新关系、新城市——是一次 $O(n)$ 的插入，不是 $O(n^2)$ 的重排。** 你走进新上下文，移过几个明显超过你的东西，嵌入你的层级，你生活的其余几乎不动。成本小，因为已排序区域本来已经稳定。你不需要重组一切——你只需要找到新拼图在已安定拼图中的位置。

但当你的生活混乱时——每个新阶段都要重排一切——每次转换都是 $O(n^2)$。每份新工作都逼你重新想整个日程。每段新关系都逼你重新谈每个已有承诺。教训：**保持你的生活近乎有序。** 维护已安定区域——已经在运作的习惯、关系、日常——这样每次插入只花它需要花的：从你所在到你适合的距离，不是从零重建的全部成本。

而最温柔的洞察：**插入排序不要求新元素比左边的一切都好。它要求它找到自己的层级。** 你不需要胜过所有人。你不需要是最好的。你要做的是走过明显比你大的东西，在属于你的地方停下，让已排序区域吸收你。目标不是在最前面。目标是*有序*——意思是恰好在适合你的地方，不高也不低。

**⚠️ 反模式**
*"加入新环境时我得从零重建一切。"* 那不是插入——那是重排整个数组。插入排序的全部前提是已排序区域*已经安定*，新元素在其中找到自己的位置。如果你把每次转换都当成全面重排——重建日程、重谈每段关系、重新定义每个角色——你在用 $O(n^2)$ 付本该 $O(n)$ 的成本。已排序区域存在是有原因的：它是之前的插入积累的秩序。尊重它。走进去。找到你的层级。只移你需要移的——只移你需要移的——让其余保持安定。插入近乎有序的生活成本很小。重排混乱的生活成本是一切。
