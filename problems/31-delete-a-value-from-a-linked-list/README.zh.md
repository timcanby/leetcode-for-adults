### 31. Delete a Value from a Linked List

> *找到并删除第一个值等于 `target` 的节点。返回新的头节点。*

**🧩 算法**
删除本身是平凡的——一行：`prev.next = cur.next`。节点没了。链表修好了。难的是删除*周围*的一切：走到正确的节点、处理目标是头节点的情况、切割时不丢线。

`dummy` 哨兵是技巧。你创建一个坐在头节点*前面*的哨兵——`dummy.next = head`——然后从 `dummy` 而非 `head` 开始走。为什么？因为如果目标*就是*头节点，你需要一个指向它的 `prev`——而头节点没有前驱。dummy *就是*那个前驱。它存在是为了让每个节点——包括头节点——身后都有人。你永远不会面对"如果删的是第一个怎么办？"的边界情况，因为 dummy 让第一个节点不再特殊。

```python
def delete_value(head, target):
    dummy = ListNode(0, head)
    prev = dummy
    cur = head

    while cur:
        if cur.val == target:
            prev.next = cur.next
            break

        prev = cur
        cur = cur.next

    return dummy.next
```

> 时间 $O(n)$ · 空间 $O(1)$

更深的原理：**你不删除那个东西——你重定向指向它的那个东西。** 节点本身没有被销毁。它被*孤儿化*了。曾经指向它的指针现在跳过了它。节点还在内存里，还持有它的值，还有它的 `next`——但没有人能到达它。它被从链上切断了，不是从存在中移除了。删除是*重路由*，不是销毁。

而 `dummy` 的智慧：**每个边界情况都有前驱——只要你创建一个。** 头节点特殊因为它是唯一没有 `prev` 的节点。dummy 移除了这种特殊性。与其把"万一删的是头？"当作一个单独情况处理，你不如让头节点*不特殊*——给它一个前驱。边界情况没消失——它*消融*了，因为创造它的条件（"没有前驱"）不复存在。你没有处理边界情况。你*消除*了它——通过改变结构让它根本不发生。

**🏢 职场**
当你解雇一个人——或移除一个项目、一个流程、一项政策——移除本身很简单：一个决定、一个宣布、一次重定向。难的是*移除周围的上下文*：走到那一步的定位、之前的对话、决定之前的对话。而最难的是：如果你要移除的是*头*——负责人、创始人、支柱？

`dummy` 的智慧：**每次移除都有上下文——只要你创建一个。** 解雇负责人比解雇任何人都难，因为负责人似乎没有前驱——上面没有人能让这次移除在结构上感觉正常。但如果你建了一个 `dummy`——一个董事会、一个顾问、一个框架、一个坐在负责人*之上*的治理结构——那负责人就不再特殊了。他们有了前驱。移除是 `prev.next = cur.next`：董事会重定向链。负责人被孤儿化，不是被销毁。组织继续走——`return dummy.next`——新负责人自然浮出。

而原理是：**你不销毁人——你重路由汇报线。** 人还在。他们的技能、关系、历史——都在。但链不再通向他们。重路由就是移除。销毁不必要——而且通常适得其反。你不需要抹除一个人来消除他的影响力。你只需重定向曾经指向他的那个指针。

**🌍 人生**
当你从生活中移除某样东西——一个习惯、一个承诺、一段关系、一个版本的自己——移除很简单：一次重定向，一句"到此为止"，一次 `prev.next = cur.next`。难的是*上下文*：定位、走到决定的那些对话、断开之前的铺垫。

而最难的是：如果你移除的是*头*——你的核心身份、你的主要角色、多年来一直是你列表起点的那个东西？"我不再是律师了。""我不再是妻子了。""我不再是有趣的那个人了。"头没有前驱。在它之前*没有东西*可以重定向。感觉像抽掉地基。

`dummy` 的智慧：**为你的身份创建一个前驱。** `dummy` 是那个在任何单一角色*之前和之外*存在的你——那个观察角色的觉知、早于工作的价值观、不等同于头衔的自我。当你有一个 `dummy`——一个不绑定在任何一个节点上的自我感——那没有角色是特殊的。移除头不是存在危机；是 `prev.next = cur.next`。角色被孤儿化，不是自我。`return dummy.next`——你成为的下一个东西自然浮出。链继续因为 dummy 一直拿着它。

而原理是：**你不销毁旧自我——你重路由。** 习惯还在记忆里。旧角色塑造了你。关系真实发生过。你不去抹除它。你重定向曾经指向它的指针。你人生的 `next` 现在指向新的方向——而旧节点坐在过去，当前链够不到，但没有被销毁。没有被遗忘。只是*不再是链去的地方*。删除是重路由，不是焚烧。而链更长——也更健康——因为被重路由了。

**⚠️ 反模式**
*"我得彻底销毁旧的才能往前走。"* 那是试图 `del` 节点而不是 `prev.next = cur.next`。你在试图从存在中抹除旧自我——旧职业、旧关系、旧习惯。但节点在内存里。它塑造了你。它的一部分。你不能 `del` 它而不腐蚀链——记忆、技能、它给你的成长。`dummy` 方法说：别销毁。重定向。旧节点不需要被抹除；它需要*从当前链不可达*。继续走。`prev.next = cur.next`。旧的你还 在内存里——塑造了你、仍然重要——但链已经继续了。`return dummy.next`。新头。新角色。新篇章。不是旧的死亡——是链的重路由。
