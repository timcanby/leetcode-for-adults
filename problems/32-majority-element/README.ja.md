### 32. Majority Element

> *⌊n/2⌋ 回より多く出現する要素を見つける。過半数が存在することが保証されている。*

**🧩 アルゴリズム**
素朴なアプローチ：ハッシュマップで各要素の頻度を数え、最も高いものを返す。$O(n)$ 時間、$O(n)$ 空間。機能する。だが必要以上のことをしている。

Boyer-Moore はもっと奇妙なことをする。数えない。**相殺する**。配列を歩き、`candidate` と `count` を持つ。`count` がゼロになったら、現在の要素を新しい候補として採用する。現在の要素が候補と一致すれば `count += 1`。一致しなければ `count -= 1`。最後に、候補*が*過半数だ。

なぜ機能するか？ 過半数は半分より多く出現するからだ。非過半数要素が過半数要素を相殺するたび、それ自身も相殺される——一対一で。だが過半数には*予備*がある。$n/2$ より多くのコピーがある。だから全相殺ペアが取り除かれた後も、過半数は生き残る。アルゴリズムが過半数を*見つける*のではない——過半数は**ゼロまで相殺できない**、それ以外の全てを合わせたより多いからだ。

```python
class Solution:
    def majorityElement(self, nums: list[int]) -> int:
        candidate = None
        count = 0

        for x in nums:
            if count == 0:
                candidate = x

            count += 1 if x == candidate else -1

        return candidate
```

> 時間 $O(n)$ · 空間 $O(1)$

より深い原理：**過半数は数えて見つけるのではない——相殺して見つける。** ハッシュマップは「各々がいくつか？」と尋ねる。相殺は「対立するものが消滅した後、何が生き残るか？」と尋ねる。過半数は*完全に相殺できない*要素だ——最良だからでも、最も声が大きいからでも、最も目立つからでもなく、*他の全てを合わせたより多い*からだ。人気コンテストではない。消耗戦で、予備のある側が勝つ。

そして保証は隠された前提だ：**これは過半数が存在する場合にのみ機能する。** $n/2$ を超える要素がなければ、アルゴリズムは*何か*を返す——だが無意味だ。相殺の生存者は「勝者」ではない；誰も予備を持たない戦いの最後の生存者にすぎない。アルゴリズムは確認しない。前提を信頼する。前提が違反されれば、答えはゴミだ。手法の正確性は前提の真実性に依存する。

**🏢 職場**
部屋の支配的な意見を見つけようとする時、投票はいらない。**相殺**が要る。各声をその対立とペアにする。「出荷すべき」vs「待つべき」。「機能は準備完了」vs「未完了」。各ペアが相殺する。全ペアが消滅した後で立っているもの——それが真の過半数だ。最も賢いからではなく、過半数の人が持ち、それに相殺する意見も*自身を相殺する*からだ。

Boyer-Moore の知恵：**票を数えるのではない——ペアを相殺する。** 混乱に感じる会議——全員が異なる意見を叫ぶ——全声を逐一集計する必要はない。部屋を歩き、誰かが現在の主導意見に反対するたびに count が下がる。賛同すれば上がる。ゼロになったら候補を切り替える。最後に立っているのが過半数——相殺できない意見、過半数の部屋が持つから。

そして保証——罠：**これは過半数が存在する場合にのみ機能する。** 部屋が 40/35/25 なら——過半数なし——アルゴリズムは*誰か*を返すが、無意味だ。最後の生存者は「コンセンサス」ではない；誰も勝たなかった消耗戦の最後の生存者だ。Boyer-Moore 会議は部屋に真の過半数がある時にのみ本物の答えを生む。なければ、決定ではない——*偽のコンセンサス*で、それに従うのは部屋が分裂していると認めるより悪い。前提——「過半数が存在する」——は技術的な詳細ではない。*全体の基盤*だ。結果を信じる前に確認せよ。

**🌍 人生**
人生の支配的な力——半数以上の日を形作る習慣、半数以上の決断を駆動する価値、半数以上の心を占める人間関係——は数えて見つかるのではない。**相殺**して見つかる。

人生を歩く。支配的なパターンに整列する各日は count に加える。矛盾する各日は引く。count がゼロになった時——十分な矛盾が蓄積しパターンを相殺した時——候補を切り替える。新しい支配的な習慣、新しい主な価値、新しい中心的人間関係を採用する。だが*真の*過半数——あなたの半数以上である力——は**完全に相殺できない**。予備がある。全矛盾を生き延びる、他の全てを合わせたより多いからだ。好みではない。過半数だ。

Boyer-Moore の自己認識アプローチ：**全思考をジャーナリングして核を見つけるのではない——ノイズを相殺して見つける。** 「本当の私ではない」各日はそうである日を相殺する。核と矛盾する各習慣はそれを表現する習慣を相殺する。だが核——あなたの半数以上——は生き残る。最良や最も声が大きいからではなく、予備があるから。他の全てを合わせたより多い。好みではなく過半数だ。

そして保証——人生の罠：**単一の力があなたの半数を超えなければ、結果は無意味だ。** 分裂していれば——40% キャリア、35% 家族、25% 自己——過半数はなく、アルゴリズムが産出する「支配的な力」は幻だ。核はない。分裂した自己があり、「答え」は誰も勝たなかった消耗戦の後の最後の断片にすぎない。自己認識の前提は：**過半数はあるか？** 一つの力——一つの価値、一人、一つの目的——があなたの半数を超えるか？ あれば、相殺が見つける。なければ、アルゴリズムはゴミを返し、過半数を*見つける*のではなく*構築する*必要がある。分裂した人生は Boyer-Moore を必要としない。*コミットメント*——何かを選び、それが半数を超えるまでの行為——を必要とする。

**⚠️ アンチパターン**
*「全てを数えて最も一般的な要素を見つける。」* それはハッシュマップ——$O(n)$ 空間、$O(n)$ 時間——過半数の保証がなくても機能する。だが問題が要求する以上のことをしている。*各々がいくつか*を知る必要はない。*何が生き残るか*を知る必要がある。相殺アプローチは $O(1)$ 空間——ハッシュマップなし、集計なし、過去の記憶なし——で機能する、過半数の生存は*数学によって保証*されており、記録保存によるのではないから。ハッシュマップは「何が最も頻繁か？」に答える。相殺は「何が排除できないか？」に答える——そして二番目の問いはより深い、過半数が単に最も一般的なものではないことを明らかにするから。それは*構造的に不可避*なものだ。人気があるから生き残るのではなく、*相殺不可*だから生き残る。それが票を数えることと消耗戦を戦うことの違いであり——頻度を知ることと*核*を知ることの違いだ。
