### 32. Majority Element

> *找出出现超过 ⌊n/2⌋ 次的元素。保证存在一个。*

**🧩 算法**
最直觉的做法：用哈希表统计每个元素的频率，返回最高的那个。$O(n)$ 时间，$O(n)$ 空间。能用。但做了你不需要的多余功。

Boyer-Moore 做的更奇怪。它不计数。它**抵消**。走过数组，持有一个 `candidate` 和一个 `count`。当 `count` 归零时，采用当前元素作为新候选。当当前元素匹配候选时，`count += 1`。不匹配时，`count -= 1`。最后，候选*就是*多数。

为什么有效？因为多数出现超过一半。每次一个非多数元素抵消一个多数元素，它自己也被抵消——一对一。但多数有*余量*。它有超过 $n/2$ 个副本。所以即使每对抵消都被移除，多数也活下来了。不是算法*找到*了多数——是多数**无法被抵消到零**，因为它比其他一切加起来都多。

```python
class Solution:
    def majorityElement(self, nums: list[int]) -> int:
        candidate = None
        count = 0

        for x in nums:
            if count == 0:
                candidate = x

            count += 1 if x == candidate else -1

        return candidate
```

> 时间 $O(n)$ · 空间 $O(1)$

更深的原理：**你不是靠计数找多数——你是靠抵消找多数。** 哈希表问的是："每种有多少？"抵消问的是："对立面湮灭后什么活下来？"多数是*无法被完全抵消*的元素——不是因为它最好、最响、最显眼，而是因为它*比其他一切加起来都多*。不是人气竞赛。是消耗战，有储备的一方赢。

而保证是隐藏前提：**这只在多数存在时有效。** 如果没有元素超过 $n/2$ 次，算法返回*某个东西*——但无意义。抵消的幸存者不是"赢家"；只是一场没人有储备的战斗中最后站着的那个人。算法不检查。它信任前提。前提被违反，答案就是垃圾。方法的正确性取决于假设的真实性。

**🏢 职场**
当你试图找房间里的主流意见时，你不需要投票。你需要**抵消**。把每个声音和它的对立面配对。"该发布"vs"该等"。"功能准备好了"vs"没准备好"。每对抵消。所有对湮灭后站着的——那是真正的多数。不是因为它最聪明，而是因为过半的人持有它，而与它抵消的意见也*抵消了自己*。

Boyer-Moore 的智慧：**你不数票——你抵消对。** 那场感觉混乱的会议——每个人在喊不同意见——你不需要逐一统计。你走一遍房间，每次有人不同意当前主导意见，count 降。每次有人同意，升。归零时换候选。最后站着的是多数——那个无法被抵消的意见，因为过半的房间持有它。

而保证——陷阱：**这只在多数存在时有效。** 如果房间是 40/35/25——没有多数——算法返回*某人*，但无意义。最后站着不是"共识"；只是一场没人赢的消耗战的最后幸存者。Boyer-Moore 会议只有在房间有真正多数时才产生真正的答案。如果没有，你没有决定——你有一个*虚假共识*，而按它行动比承认房间分裂更糟。前提——"存在多数"——不是技术细节。它是*整个地基*。信结果前先检查它。

**🌍 人生**
你人生的主导力量——塑造过半日子的习惯、驱动过半决策的价值观、占据过半内心的关系——不是靠计数找到的。是靠**抵消**找到的。

走一遍你的人生。每一个与主导模式对齐的日子加一。每一个违背的日子减一。当 count 归零——当足够多的矛盾堆积到抵消掉模式时——你换候选。你采用一个新的主导习惯、一个新的主要价值观、一个新的核心关系。但*真正的*多数——那个超过你一半的力量——**无法被完全抵消**。它有储备。它挺过每次矛盾，因为它比其他一切加起来都多。不是偏好。是多数。

Boyer-Moore 的自我认知方式：**你靠的不是记每个想法的日记——你靠的是抵消噪声。** 每个"不是真正的我"的日子抵消一个是的日子。每个与核心矛盾的习愵抵消一个表达它的。但核心——超过你一半的那个——活下来了。不是因为它最好或最响，而是因为它有储备。比其他一切加起来都多。不是偏好。是多数。

而保证——人生的陷阱：**如果没有任何单一力量超过你的一半，结果无意义。** 如果你是分裂的——40% 职业、35% 家庭、25% 自我——没有多数，算法产出的"主导力量"是幻影。你没有核心。你有一个分裂的自我，而"答案"只是消耗战后没人赢时最后站着的碎片。自我认知的前提是：**有多数吗？** 有没有一个力量——一个价值观、一个人、一个使命——超过你的一半？如果有，抵消能找到它。如果没有，算法返回垃圾，你需要*建造*一个多数——不是*找*一个。分裂的人生不需要 Boyer-Moore。它需要一次*承诺*——选择某样东西直到它超过一半的行动。

**⚠️ 反模式**
*"我数一切来找到最常见的元素。"* 那是哈希表——$O(n)$ 空间、$O(n)$ 时间——即使没有多数保证也能用。但它在做超出问题要求的工作。你不需要知道*每种多少*。你需要知道*什么活下来*。抵消的做法花 $O(1)$ 空间——没有哈希表、没有统计、没有对过去的记忆——因为多数的存活*由数学保证*，不是靠记台账。哈希表回答"什么最频繁？"抵消回答"什么无法被消除？"——而第二个问题更深，因为它揭示了多数不只是最常见的东西。它是*结构上不可避免*的东西。活下来不是因为它流行，而是因为它*不可抵消*。这就是数票和打消耗战的区别——也是知道你的频率和知道你的*核心*的区别。
