### 33. Longest Palindromic Substring

> *找出最长的、正读反读都一样的子串。*

**🧩 算法**
暴力检查每个子串是 $O(n^3)$——太慢。DP 的洞见：你不是从头证明一个大子串是回文。你通过查两件便宜的事来证明：

1. 两**端**匹配吗？（`s[i] == s[j]`）
2. 它们之间的**内部**已经是回文了吗？（`dp[i+1][j-1]`）

如果两者都真，`s[i..j]` 就是回文。"内部已解"那部分是递归——你已经算过所有更短的子串，所以中间那段的答案就躺在那等着。

```python
def longestPalindrome(s):
    n = len(s)
    dp = [[False] * n for _ in range(n)]
    start = 0
    best = 1
    for i in range(n - 1, -1, -1):
        for j in range(i, n):
            if s[i] == s[j] and (j - i <= 2 or dp[i+1][j-1]):
                dp[i][j] = True
                if j - i + 1 > best:
                    start = i
                    best = j - i + 1
    return s[start:start + best]
```

> 时间 $O(n^2)$ · 空间 $O(n^2)$

更深的原理：**长的回文不过是戴着匹配两端的短回文。** 你不直接造那个大的对称体。你先造小的，然后问："如果内部已经完整，我能在外面套两个匹配字符吗？"那就是全部方法。内部做重活；两端只是 $O(1)$ 的检查。

而循环顺序重要——`i` 往**后**走（`n-1 → 0`），`j` 从 `i` 往前走。在 `dp[i+1][j-1]` 存在之前你填不了 `dp[i][j]`，所以你必须先解*更小*的问题（更短的子串、更大的 `i`）。**你在每个小尺度上证明对称性之前，无法在大尺度上认证它。** 顺序不是装饰——它就是*依赖关系*。

**🏢 职场**
组织里的"回文"是一个从*两个*方向都连贯的决定或叙述——自上而下讲的故事和自下而上的现实。当领导说一套、一线活的是另一套，那子串不是回文。它碎了。

DP 的教训：**别试图一下让整个组织连贯。** 先在局部建立连贯。让小团队成为回文——他们宣称的目的匹配实际行为（`s[i] == s[j]`），而他们*之间*的团队已经健康（`dp[i+1][j-1]`）。一旦内部完整，更大的组织只需要两端匹配。大的回文只是带着匹配边界的小回文——不是自上而下的重写。

而循环顺序：**在断言外层叙述前先修内部功能失调。** 一个宣布"我们现在对齐了"但中间团队还碎着的组织重构是 `dp[i][j] = False`——`dp[i+1][j-1]` 检查失败。你在每个小单位已经连贯之前无法认证全组织对称。从内部开始。向外工作。中间立住了，两端就便宜。

**🌍 人生**
一个正反读都一样的生命是一个有**integrity（知行合一）**的生命——你宣称的价值观从每个角度都匹配你实际的行为。这样最长的子串是你生命里最长的、你说的自己和真实的自己对齐的那段。

DP 的教训：**你不是用一个宏大姿态达成 integrity 的。** 你在局部达成它。每个小的选择是一次回文检查：这句话匹配这个边缘的行为吗（`s[i] == s[j]`），它们之间的生命段已经连贯了吗（`dp[i+1][j-1]`）？两者都真，那段就完整。integrity 的不间断长段不是靠一个大决心建的——它靠成千上万个小回文，每个都给一个先前完整的内部套上两个匹配端。

而循环顺序——最重要的部分：**你从内向外、先小后大地建 integrity。** 你在较小段已经完整之前，无法认证你的*整个生命*连贯（`dp[0][n-1]`）。一个宣布"我完全变了"但内部还矛盾的人，是在 `dp[i+1][j-1]` 存在前查 `dp[i][j]`——它返回假。先改变内部。让两端跟随。生命的最长回文是一次一个小连贯段挣来的。

**⚠️ 反模式**
*"我就把整个生命/组织重写到连贯——从外面重新开始。"* 那是在 `dp[i+1][j-1]` 存在前就算 `dp[i][j]`。你宣布那个大回文——"新的我"、"对齐的团队"、"转型的文化"——但内部还碎着，所以检查失败。两端甚至可能匹配（你现在*说*对了话），但没有连贯的中间，整个是 `False`。DP 方法拒绝这个：它只在内部*已经是*回文的子串上扩展对称。你不是靠强迫外字符匹配就得到一个长回文。你靠让内部完整、再包住它来得到。先小。让内部为真。让长度生长。向外扩展连贯是便宜的——*向内挣得*它是活儿。
